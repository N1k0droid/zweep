# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately to **nicodroidprojects+zweep@gmail.com**, never in public
issues. Include the affected version, a description and, if possible, the steps to reproduce.

Zweep is a free, community open source project maintained on a best-effort basis: reports are
looked at as time allows, and fixes, when available, are released in the latest version. There is
no guaranteed response time or support period. Please allow time for a fix before disclosing.

## Supported versions

Only the latest release.
